# Zen Writer

Zen Writer — минималистичная полноэкранная «печатная машинка» для Raspberry Pi 4.
После загрузки Raspberry Pi OS приложение открывает последний текст и возвращает
курсор туда, где пользователь остановился.

## Возможности первой версии

- обычные UTF-8 файлы `.md` и `.txt` в выбранной папке;
- скрытая панель файлов;
- Markdown-подсветка без изменения исходного текста;
- атомарное автосохранение через 1,5 секунды после ввода;
- резервная копия перед первым изменением и затем не чаще раза в пять минут;
- до 50 резервных копий каждого документа;
- русский и английский Hunspell;
- счётчик слов и символов, общая дневная цель;
- режим печатной машинки с текущей строкой по центру;
- таймер, поиск и замена;
- светлая, тёмная и сепия-темы, фоновое изображение;
- Matrix-тема с лёгким анимированным кодовым дождём и неоновой палитрой;
- переназначаемые клавиши сохранения, поиска и выхода;
- автоматическое открытие последнего файла;
- безопасное выключение Raspberry Pi с подтверждением.

## Установка на Raspberry Pi OS

Рекомендуется Raspberry Pi OS Bookworm 64-bit с рабочим столом.

```bash
git clone https://github.com/kekuskekus/zen-writer.git
cd zen-writer
bash scripts/install-raspberry-pi.sh
sudo reboot
```

Запускайте установщик от обычного пользователя рабочего стола, **без `sudo`**:
он сам запросит административные права для установки пакетов и бинарника.
Установщик собирает приложение нативно, устанавливает Qt-плагин Wayland,
добавляет единую запись XDG-автозапуска и включает автоматический вход в рабочий
стол через `raspi-config`. Этот способ работает в штатных сеансах Raspberry Pi OS
labwc, Wayfire и X11/LXDE; наличие установленного `labwc` больше не определяет
выбор автозапуска. Тексты по
умолчанию находятся в `~/Documents/Zen Writer`. Папку можно сменить сочетанием
`Ctrl+Shift+O`, в том числе на подключённую USB-флешку.

### Обновление и проверка запуска

В папке репозитория:

```bash
git pull --ff-only
bash scripts/install-raspberry-pi.sh
/usr/local/bin/zen-writer-launch --fullscreen
```

Версия после установки должна быть `0.2.2` или новее. Одного `git pull`
недостаточно: установщик должен пересобрать и заменить `/usr/local/bin/zen-writer`.
После проверки ручного запуска перезагрузите Raspberry Pi для проверки автозапуска.

Начиная с 0.2.2 ярлык меню и автозапуск используют `zen-writer-launch`.
Он сохраняет ошибки Qt и фактическую платформу окна в журнал. Если окно не появилось:

```bash
tail -n 80 "${XDG_STATE_HOME:-$HOME/.local/state}/zen-writer/launch.log"
```

Без `DISPLAY`/`WAYLAND_DISPLAY` обычный SSH-сеанс не является графическим рабочим
столом: программа сообщит об этом в журнале. Явный `QT_QPA_PLATFORM` сохраняется;
без него launcher выбирает Wayland с резервным X11 либо обычный X11.

Автозапуск находится в `${XDG_CONFIG_HOME:-$HOME/.config}/autostart/zen-writer.desktop`.
Установщик убирает только старые команды Zen Writer из пользовательского
`labwc/autostart`, сохраняя остальные строки. Изменяемые файлы копируются рядом
с суффиксом `.zen-writer-backup-...`; резервные копии не запускаются автоматически.
Устаревшая запись XDG в прежней папке настроек также переносится в резервную копию.
Повторный автозапуск защищён блокировкой; после `Ctrl+Q` приложение не перезапускается.

Вне штатного рабочего стола Raspberry Pi OS (например, в самостоятельно
настроенном «чистом» labwc) должен быть включён обработчик XDG-автозапуска.
Установщик не меняет системные конфиги оконного менеджера и не добавляет
дублирующий запуск в `labwc/autostart`.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `Ctrl+O` | показать или скрыть список файлов |
| `Ctrl+N` | создать текст |
| `Ctrl+Shift+O` | выбрать папку с текстами |
| `Ctrl+S` | сохранить сейчас (можно переназначить) |
| `Ctrl+F` | поиск и замена (можно переназначить) |
| `Ctrl+T` | запустить таймер |
| `Ctrl+,` | настройки оформления и цели |
| `Ctrl+Alt+T` | режим печатной машинки |
| `Ctrl+Alt+S` | проверка орфографии |
| `Ctrl+Alt+M` | включить или выключить Matrix-тему |
| `F11` | переключить полный экран |
| `Ctrl+Q` | выйти на рабочий стол (можно переназначить) |
| `Ctrl+Shift+Q` | безопасно выключить Raspberry Pi |

Чтобы изменить `Ctrl+S`, `Ctrl+F` или `Ctrl+Q`, откройте настройки через
`Ctrl+,` и нажмите «Горячие клавиши → Настроить…». Zen Writer не позволит
назначить одинаковые сочетания, перехватить фиксированную команду или привязать
обычную букву без `Ctrl`, `Alt` или `Meta`. Кнопка «Восстановить значения по
умолчанию» возвращает исходные сочетания.

Удаление всегда использует системную корзину. Если корзина недоступна, Zen
Writer оставляет файл на месте.

## Ручная сборка

Требуются CMake 3.20+, Qt 6.4+ и, опционально, Hunspell.

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
./build/zen-writer --windowed
```

Без параметров приложение открывается на весь экран. Параметр `--fullscreen`
явно включает этот режим и используется ярлыком Linux и автозапуском.
`--windowed` (или `-w`) открывает обычное окно и имеет приоритет, если указаны
оба параметра.

В версии 0.2.1 исправлен запуск из меню Linux: раньше ярлык передавал
`--fullscreen`, который программа не распознавала. Если старая версия не
открывается из меню, временно запустите `/usr/local/bin/zen-writer` без параметров.
После обновления исходников повторите запуск установочного скрипта, чтобы
заменить установленный бинарник. Уже созданные ярлыки менять не требуется.

Linux-тесты запускают настоящий бинарник в изолированном временном профиле
через Qt offscreen, в том числе с аргументами из `.desktop`-файла. Они проверяют,
что приложение не завершается сразу после запуска; это не заменяет проверку
отрисовки на конкретном дисплее Raspberry Pi.
Также проверяются миграция автозапуска, повторная установка, пользовательские
пути XDG, сохранение резервных копий, выбор Qt-платформы, логирование ошибок
и блокировка повторного автозапуска.

Синхронизация намеренно не входит в первую версию. Поскольку документы остаются
обычными файлами, позже можно безопасно добавить Syncthing или `rclone`, не меняя
формат данных приложения.

## Windows

Готовая Windows x64 сборка публикуется как артефакт `ZenWriter-Windows-x64.zip` в
GitHub Actions. Распакуйте ZIP и запустите `zen-writer.exe` для portable-режима.

Чтобы установить приложение в `%LOCALAPPDATA%\ZenWriter`, добавить его в
автозапуск и сразу открыть, запустите из распакованной папки:

```powershell
.\Install-ZenWriter.ps1
```

Параметр `-NoAutostart` отключает создание ярлыка автозапуска, а `-Windowed`
запускает первое окно не на весь экран. Windows-сборка использует системные
словари русского и английского языков; доступность словарей зависит от языковых
компонентов, установленных в Windows.
